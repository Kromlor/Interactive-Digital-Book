# Interactive Digital Book (Character Books)

A choose-your-own-adventure reading app for grade 6 and up. Students create a character, play a book, and get a **character code** that carries their character into the next book.

**Current version: v0.6**

## Series
- **The Ember Frontier** (sci-fi)
- **Under the Lights** (football)
- **Oathbound** (fantasy)
- **Wildborn** (animal adventure): three books, *The Summer the River Dropped*, *Smoke on the Buttes*, *The First Hard Snow*

## How it works
- One file: `index.html`. Open it in Chrome or Edge, or host it on GitHub Pages.
- No logins, no accounts and no student data. Characters are saved only in the browser on that device. Names are never put in character codes.
- To move a character to another device, copy its character code and paste it in with **I have a character code**.
- The only internet it needs is for the Google fonts.

## Updating
Download the new `index.html` → **Add file → Upload files** → **Commit changes**. If GitHub Pages is on, the live site updates in about a minute.
